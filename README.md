# LibreríaQR

SaaS multi-tenant para papelerías/librerías: reciben, cotizan y cobran pedidos de útiles escolares y libros sin atención presencial masiva.

## Arquitectura
- **Backend:** Node.js + TypeScript (orquestación, WhatsApp, IA)
- **Paneles:** Next.js
- **Base de datos:** SQLite (piloto), VPS PostgreSQL (producción)
